# Data Analysis and User Profiling

## Project Overview
Proyek ini bertujuan untuk mengolah data mentah transaksi menjadi wawasan strategis yang dapat ditindaklanjuti. Fokus utama dari analisis ini adalah implementasi **Customer Segmentation & Profiling** menggunakan metode statistik dan segmentasi bersyarat (RFM Analysis).

Metodologi pengolahan data dan proses *clustering* yang digunakan dalam proyek ini sangat relevan dan dapat diadaptasi untuk kebutuhan **Human Resources**, khususnya pada inisiatif:
* Penyusunan Profil Individu berdasarkan agregasi skor *assessment*.
* *Talent Mapping* secara kuantitatif (contoh: 9-Box Grid Matrix).
* Pemetaan distribusi potensi dan performa karyawan secara terstruktur.

## Tech Stack & Skills Demonstrated
* **Data Wrangling & Cleaning:** Menggunakan Python (Pandas, NumPy) untuk menangani *missing values*, data duplikat, serta penggabungan (merging) multi-tabel dari berbagai sumber data.
* **Data Profiling & Clustering:** Memetakan populasi data berskala besar ke dalam segmen-segmen terarah berdasarkan parameter yang ditentukan guna mempermudah identifikasi karakteristik populasi.
* **Data Visualization:** Menyajikan distribusi populasi dan matriks demografis menggunakan Seaborn dan Matplotlib untuk mempermudah pembacaan data.

## Repository Structure
* `submission/` : Direktori yang memuat keseluruhan file proyek, termasuk Jupyter Notebook yang berisi dokumentasi komprehensif alur kerja data (Extract, Transform, Exploratory Data Analysis, hingga formulasi logika Clustering), serta script aplikasi dashboard.

## Key Takeaways
Melalui pipeline data ini, raw data yang kompleks berhasil diproses dan dikelompokkan menjadi segmen-segmen yang spesifik. Hasil pemetaan ini divisualisasikan untuk memfasilitasi pemangku kepentingan (stakeholders) dalam membaca persebaran data secara efisien dan merancang strategi intervensi yang tepat sasaran.
